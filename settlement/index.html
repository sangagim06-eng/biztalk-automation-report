Business Transformation

이전 방식(As-Is) vs 현재 시스템(To-Be) 비교

수기 방식에서 발생하던 휴먼 에러와 인수인계 공백을 완벽히 차단했습니다.

이전의 업무 방식 (As-Is: 구글 시트 수기 취합)
  • 시트 파편화: 구글 드라이브 내 수많은 시트가 흩어져 가로로 길어 담당자 확인이 어렵고 누락 빈번
  • 계정 관리 혼선: 13개 이상 포털의 ID/PW가 텍스트로 보관되어 찾기 번거롭고 OTP 인증 여부 불명확
  • 복잡한 특수 공식 오류: 메리츠 2건 분리발행(VAT포함), 엠콘네스트(0.7원/싱크고정), 블루닉 재산정 수작업 계산 착오
  • 인수인계 공백: 신규 담당자가 오면 어떤 업체부터 먼저 처리해야 하는지 파악 불가
스마트 정산 허브 도입 후 (To-Be: 원스톱 자동화)
  • 3단 캘린더 대시보드: 1일, 10일, 말일 등 날짜만 누르면 당일 마감 업체가 중앙과 우측에 즉시 표출
  • 원클릭 계정 금고: 13개 사이트 바로가기 및 ID/PW 1초 복사, SMS/OTP 인증 가이드 통합
  • 엑셀 드래그 자동 계산 엔진: BMS 통계 파일 올리면 건수 인식 + 특수 공식 자동 대입 + 명세서 생성
  • 경영지원부(MS) 연동 & 백업: 세금계산서 요청 메일 1초 복사 + 엑셀 다운로드 + 브라우저 자동 저장
End-to-End Operational Lifecycle

담당자의 실제 5단계 업무 라이프사이클 흐름도

누가 오더라도 아래 5단계를 따라가면 1개 업체 정산을 1분 안에 완료합니다.

01 마감일 확인

정산 캘린더 탐색

달력에서 오늘 날짜(예: 1일, 10일)를 클릭하여 오늘 마감인 정산 고객사(한미, 무신사, DB 등) 목록을 필터링합니다.

Calendar View
02 통계 수집

사이트 로그인 & 다운로드

[업무 사이트 금고]에서 BMS, 비즈고, 카카오모먼트 포털에 1클릭 복사한 ID/PW로 로그인 후 발송 통계 엑셀을 받습니다.

Credential Vault
03 데이터 입력

통계 엑셀 드래그&드롭

다운로드한 엑셀 파일을 자동 계산기 드롭존에 끌어다 놓으면 SheetJS 파서가 성공건수와 품목을 1초 만에 추출합니다.

SheetJS Parser
04 규칙 산출

고객사별 특수 공식 적용

메리츠 2건 분리역산기, 엠콘네스트(0.7원+고정비), 블루닉 단가 등 사전 프로그래밍된 공식 엔진이 자동 계산합니다.

Rule Engine
05 발행 & 공유

명세서 다운로드 & MS 메일

정식 거래명세서 엑셀을 저장하고, 'MS 공유 메일 복사' 버튼으로 세금계산서 발행 요청 본문을 복사하여 송부합니다.

Export & Share
System Architecture

4계층 기술 아키텍처 다이어그램 (4-Tier Stack)

프론트엔드 React / Vite 환경에서 단단하게 맞물려 돌아가는 컴포넌트 및 데이터 계층 구조입니다.

Layer 1

UI & 워크스테이션 프레젠테이션 계층 (Presentation Layer)

React 19 + Tailwind CSS + Lucide Icons
📅 3단 캘린더 대시보드 좌측 카테고리/일자/캘린더 + 중앙 리스트 + 우측 인스펙터
📊 와이드 시트 표 뷰 구글 드라이브 시트처럼 가로로 시원하게 전체 열을 조회하는 테이블
⚡ 자동 정산 계산기 뷰 파일 드롭존, 수량·단가 실시간 편집기, 공급가/부가세 자동 산출
🔑 사이트 금고 & 현황판 13개 포털 계정 카드, 쉐어포인트 문서함, 월별 진행률(%) 체크리스트
Layer 2

비즈니스 룰 & 고객사별 공식 엔진 (Business Logic & Rule Engine)

Formula Dispatcher & Reverse VAT Calculator
엠콘네스트 알고리즘 한국리서치 건수 × 0.7원 (120~130만건 조정) + 네파/폴바셋 144만 고정비
메리츠화재 역산 분리기 고객사 회신 총액(VAT포함) 입력 시 1차/2차 공급가액·부가세 자동 분할
블루닉/민주당 약정단가 알림톡 1.68원 / SMS 1.0원 / LMS 1.9원 / MMS 0원 자동 재산정
특수 정산 룰셋 인포마인(태안모터스 제외/수동충전삭제), 어다인(×0.1원), 웰리힐리 등
Layer 3

엑셀 파서 & 문서 출력 변환 엔진 (Parser & Export Engine)

SheetJS (xlsx) + Korean Currency Formatter
Intelligent Excel Parser .xlsx, .xls, .csv 업로드 시 '성공건수', '서비스명', '단가' 열 자동 매핑
거래명세서 엑셀 내보내기 공급자·공급받는자·품목·세액 완비된 정식 서식 엑셀 즉시 생성
한국어 금액 표기 변환 합계 금액을 "일금 천이백오십만원정 (₩12,500,000)" 규격으로 한글 변환
인쇄 & 메일 클립보드 브라우저 Clean Print CSS 지원 및 경영지원부 요청 메일 텍스트 복사
Layer 4

데이터 지속성 & 스토리지 계층 (Data Persistence Layer)

Browser LocalStorage + Bulk Import Engine
기본 43개 고객사 DB 스크린샷 수치(수기정산 31, 지출정산 11 등) 100% 매칭 내장 데이터
신규/기타 업체 등록 사용자가 추가한 업체 정보를 브라우저 로컬 저장소에 영구 보존
구글 시트 Bulk Import 외부 엑셀 파일 업로드로 수십~수백 개 업체를 한 번에 일괄 추가
월별 진행 현황 지속성 월별 체크리스트(미착수, 명세서작성, 완료) 및 작업 메모 영구 저장
Special Rules Engine

시스템에 프로그래밍된 5대 고객사 특수 공식

기존에 엑셀 수식이나 수작업으로 실수하기 쉬웠던 공식들이 자동화되어 있습니다.

10일 마감 | 메리츠화재 2건 분리발행

VAT 포함 회신액 역산 분리기

고객사가 회신하는 분리 금액은 VAT가 포함된 금액입니다. 시스템이 공급가 = Math.round(회신액 / 1.1)로 역산하여 1차 및 2차 공급가액/세액을 1원의 오차 없이 2장의 공문으로 분리 산출합니다.

총액 → 1차(60%) & 2차(40%) 공급가/세액 분리
전전월 마감 | 엠콘네스트 비율 + 싱크 고정비

한국리서치 0.7원 & 싱크 144만

전전월 @한국리서치 성공 건수에 0.7원을 곱하고(120만~130만건 조정 가이드), 여기에 네파 750,000원 + 폴바셋 690,000원의 월 고정 이용료를 합산하여 최종 거래명세서를 산출합니다.

(성공건수 × 0.7) + 네파(75만) + 폴바셋(69만)
전월 마감 | 블루닉 더불어민주당

4대 약정 단가 자동 재산정

BMS 통계에서 다운로드받은 건수에 대해 약정 단가를 일괄 재적용합니다: 알림톡 1.68원, SMS 1.0원, LMS 1.9원, MMS 0원(무과금)으로 재산정한 거래명세서를 자동 작성합니다.

알림톡: 1.68 | SMS: 1.0 | LMS: 1.9 | MMS: 0
Zero-Handover Barrier

"누가 오더라도 3분 안에 마스터하는 인수인계 프리 보장"

담당자가 휴가를 가거나 인수인계가 발생해도 아래 3중 안전장치로 누락과 실수를 원천 차단합니다.

정산 시스템 바로 실행하기
사전 체크리스트 (2~3 체크)

각 업체마다 "카카오 통계 비교", "선청구 상태 변경", "담당자별 분리 발송" 등 반드시 확인해야 할 체크박스가 내장되어 있어 누락이 불가능합니다.

3분 신규자 가이드 모달

상단 버튼 하나로 4단계 기본 정산 절차와 자주 실수하는 6대 주의사항(메리츠 분리, 엠콘네스트 고정비, LG유플러스 절사 등)을 열람할 수 있습니다.

원클릭 메일 템플릿 복사

정산이 끝나면 클릭 한 번으로 경영지원부(MS) 전달용 제목, 공급가액, 세액, 상세 품목표가 클립보드에 완벽한 양식으로 복사됩니다.
